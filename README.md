# نظام المحاسبة المتكامل — لوجه الله

نظام محاسبة عربي متكامل (رسمي للمكاتب المحاسبية ومكاتب إدارة الميزانية)، مجاني 100% لوجه الله.

## المميزات
- دليل حسابات + شجرة حسابات
- دفتر قيود اليومية (مسودة / ترحيل / تسوية / افتتاحي / إقفال)
- الأستاذ العام + ميزان المراجعة
- موازنة تقديرية ومقارنتها بالمصروف الفعلي
- مناطق / فروع منفصلة (مركز رئيسي، أقاليم...)
- صلاحيات: مدير / محاسب / مشاهدة فقط
- تصدير Excel رسمي (أسود Bold + حدود + توقيعات قابلة للتعديل)
- نسخ احتياطية تلقائية شهرية + استيراد من Excel
- استعادة النسخ الاحتياطية من ملف (.db) يختاره المستخدم من جهازه
- نسيت كلمة المرور؟ — استعادة عبر سؤال الأمان (يُفعّل من صفحة المستخدمين)
- سكربت ترقية `upgrade.py` لقواعد البيانات القديمة
- سجل عمليات + حماية من تكرار القيود
- قاعدة بيانات SQLite — لا تحتاج تركيب

## التشغيل
```bash
pip install -r requirements.txt
python app.py
```
ثم افتح `http://localhost:5000`

دخول تجريبي:
`admin / admin123` (مدير) — `ahmed / ahmed123` (محاسب) — `viewer / viewer123` (مشاهدة)

> ⚠️ غيّر كلمات المرور من الإعدادات فور أول استخدام.
> 🛡️ لتفعيل «نسيت كلمة المرور؟» — من صفحة **المستخدمون** اضغط «سؤال أمان» لكل مستخدم وأدخل السؤال والإجابة.
> 🔄 عند فتح نسخة قديمة: شغّل `python upgrade.py` أولًا (يعمل نسخة أمان ثم يرقّي القاعدة تلقائيًا).
## النسخة الجاهزة
من ملف `نظام المحاسبة - نسخة التشغيل.zip` —
نسخة EXE تعمل بدون تركيب.

## الوصول من خارج البيت (عبر الراوتر)
- `تشغيل الجهاز الرئيسي للوصول من خارج البيت.bat` — على الجهاز الرئيسي:
  يفتح جدار الحماية للمنفذ 5000، يشغّل النسخة بجانبه تلقائياً (الـ EXE أو
  الكود المصدري)، ويعرض العناوين المحلية والعامة.
- `الاتصال من خارج البيت.bat` — على الأجهزة البعيدة: يفتح نظام المحاسبة.
- كلا النسختين على المنفذ 5000. التفاصيل الكاملة لفتح منفذ الراوتر و DDNS
  في `دليل الربط من خارج البيت.txt`.
